# Changelog

## 0.2 – November 16, 2026

- The app is now called Proledo and has a new, simpler icon.
- Long videos can be downloaded as a clip, so the file stays small.
- Before downloading you see a preview, the length and a rough size.
- The menu bar and Dock can be hidden per monitor.
- Videos fade in and blend into each other.
- Right-click the icon for a small quick menu.
- Proledo can start automatically when you log in.

## 0.1 – November 16, 2026

- First version: a YouTube video as a moving wallpaper, set per monitor.
